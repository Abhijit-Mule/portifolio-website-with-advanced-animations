# Abhijit Mule — Portfolio

A modern, responsive developer portfolio built with React and Vite. The design focuses on clean typography, subtle motion-ready interactions, strong project presentation and a premium dark visual system.

## ✨ Highlights

- Responsive portfolio layout
- Dark premium UI
- Smooth anchor navigation
- Interactive project cards
- Skills, projects, achievements and contact sections
- SEO-ready document metadata
- Easy-to-customize React structure

## 🛠️ Tech Stack

- React
- Vite
- CSS
- JavaScript

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.
